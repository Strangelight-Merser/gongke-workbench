# 2026-11-02 本机交付记录

范围由用户确认：先完成本机 macOS Apple Silicon 可交付版本；真实模型服务和 Windows＋SOLIDWORKS/AutoCAD 环境待补。本轮未对外发布。

## 已修复

- 空工程直接填写任务书，寿命条件可编辑；教学标记明确保留。手动和助手共用任务书保存及校验。
- 助手接收当前选择，跨发送、重开保留工程内对话和真实工具结果。不同工程隔离，同工程不并发执行两轮助手任务；中断动作不自动重放。
- 生成记录绑定提交时的任务书及教学标记，包含产物、图检及失败状态。条件变化使旧成果过期；文件缺失或最新生成失败不会沿用历史成功。
- 图纸和说明书按修订分组，文件预览和底部修订状态显示当前/历史关系。默认完整生成包含 Word 说明书。
- 模型密钥默认仅本次会话使用，显式勾选后才访问系统钥匙串并加密保存，避免未选择保存时阻塞界面。最终复验包含密钥未落盘断言。
- FreeCAD 保存工作副本或导出 DXF 后自动刷新工程文件列表。
- 任务页可读取操作回执。任务仍在执行时阻止切换工程，避免旧任务影响新工程。
- 原始测试仅按用户明确授权增加导航、空历史替身和异步输入等待；原断言和验收数据保留。新增独立回归与端到端验收。
