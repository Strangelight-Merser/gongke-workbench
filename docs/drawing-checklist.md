# 工程图自查清单

对照课程设计指导书和教材样图的通行要求，逐项检查自动生成的图纸。每次改图后按此清单目视复查一遍
（`python -m gongke_core design ... --no-step` 后看 `drawings/drawings.pdf`），能自动检查的项目写进了 `tests/drawing`。

状态：✓ 已做到；△ 部分做到或简化；✗ 尚未做。

## 全部图纸

| 要求 | 状态 | 说明 |
|---|---|---|
| 文字之间不重叠，图线不穿过尺寸数字和文字（GB/T 4458.4：无法避免时图线断开） | ✓ | `drawing/lint.py` 自动检查，`tests/drawing` 要求五个方案都为 0；中心线、细实线、尺寸界线遇文字自动断开，引出标注、粗糙度、形位公差框格按周围图线自动选位置 |
