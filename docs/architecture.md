# 架构说明

> 2026-10-19 定稿第一版。记录"做什么、不做什么、为什么这样分层"。

## 1. 要解决的问题

机械类学生做"二级圆柱齿轮减速器课程设计"时，通常要在 4–5 个软件之间来回切换：

| 环节 | 现在常用的工具 | 本项目里对应的模块 |
|---|---|---|
| 电机选择、传动比分配、各轴参数 | 手算 / Excel | `gongke_core.calc.kinematics` |
| 齿轮、轴、轴承、键的强度计算 | 手算 / 查手册 | `gongke_core.calc.*` |
| 轴的结构设计、箱体尺寸 | 草图纸 / AutoCAD | `gongke_core.layout` |
| 三维建模与装配 | SolidWorks / UG | `gongke_core.geometry`（OCCT） |
| 二维工程图 | AutoCAD / CAXA | FreeCAD TechDraw（后续） |
| 计算说明书 | Word 手写公式 | `gongke_core.report` |

"一个应用里集成一个专业的各类软件功能"，第一步就是把这条链路打通：**输入一张设计任务书，得到计算结果、三维装配体和计算说明书**，而且每一步的中间数据都在同一个模型里，改一个参数，后面全部重算。

## 2. 分层

```
设计任务书 (YAML / 界面表单)
        │
        ▼
gongke_core.design.ReducerDesign      ← 总调度，纯 Python
  ├─ calc.kinematics   电机选择、传动比分配、各轴 P/n/T
  ├─ calc.gear         斜齿圆柱齿轮：设计 + 接触/弯曲校核
  ├─ layout.reducer    箱体尺寸、轴向布置、各轴阶梯结构
  ├─ calc.shaft        受力、弯矩图、弯扭合成校核
  ├─ calc.bearing      深沟球轴承选型与寿命
  └─ calc.key          平键选型与挤压校核
        │  （全部结果是普通 dataclass，可序列化为 JSON）
        ├──────────────► report     计算说明书 DOCX / Markdown
        ├──────────────► drawing    ezdxf 按 GB 规定画法绘制装配图、零件图 → DXF（+ SVG 预览）
        └──────────────► geometry   build123d/OCCT 生成齿轮、轴、轴承、箱体 → STEP
                                    │
                                    ▼
                         freecad/gongke 工作台：表单输入、调用核心、导入 STEP、出图
```

### 为什么这样分

1. **计算与界面分离**：`gongke_core` 不依赖 FreeCAD，可以在任何 Python 3.10+ 上用 `pytest` 测试，也可以单独作为命令行工具使用（`python -m gongke_core design 任务书.yaml`）。
2. **几何由核心生成，FreeCAD 只负责导入**：FreeCAD 自带的 OCCT 与 pip 上的 OCP 不能保证在同一进程共存，所以工作台通过**独立进程**调用核心生成 STEP，再用 `Import.insert` 导入。这与 CalculiX、LibreDWG 的调用方式一致，也让几何生成可以在 CI 里无头测试。
3. **工程图不从三维模型投影**：GB 规定画法（齿轮只画齿顶线、分度线、齿根线；轴不剖；轴承用通用画法；键槽用移出断面）本来就是"按参数画"，从三维投影反而要去掉齿形、隐藏线和螺旋线。所以 `drawing` 直接读设计结果绘制，尺寸与计算完全一致。输出 DXF 是因为学生最终都要在 AutoCAD / 中望 CAD 里修改和打印；齿轮腹板等结构尺寸由 `layout.gear_blank` 统一给出，三维和二维共用。
4. **布置（layout）单独成层**：轴的受力校核依赖齿轮在轴上的位置，位置又依赖齿宽、轴承宽度和箱体壁厚。把"尺寸怎么定"集中在 `layout`，计算模块只接受确定的几何输入，便于单独测试。

## 3. 第一版功能范围

**做：**

- 传动方案：电动机 → 联轴器或普通 V 带传动 → 展开式二级斜齿圆柱齿轮减速器 → 联轴器 → 卷筒（带式输送机），这是最常见的课程设计题目。V 带方案先按预定带传动比设计 V 带，带轮直径圆整后用实际带传动比重新分配减速器传动比（`calc/vbelt.py`、`layout/pulley.py`）。
- 电机选择（Y 系列 4 极 / 6 极）、传动比分配 `i₁ = √(1.3 i)`。
- 斜齿轮按接触强度设计、按弯曲强度确定模数，圆整中心距后反算螺旋角并校核；不满足时自动加大中心距重算。
- 轴：最小直径估算、阶梯轴结构自动生成、两平面受力和弯矩、弯扭合成校核；判断是否需要做成齿轮轴。
- 深沟球轴承按寿命选型（不够时在同内径下换更重的系列）。
- 平键选型和挤压强度校核（不够时加长或改双键）。
- 箱体主要尺寸（壁厚、凸缘、地脚螺栓等经验公式）。
- 三维：渐开线斜齿轮、阶梯轴（含键槽）、轴承、简化箱体，组成装配体导出 STEP。
- 计算说明书 DOCX，带公式、取值依据和校核结论。
- 二维工程图：装配图（主、俯、左三视图，含明细栏、技术特性表）和轴、齿轮、箱座、箱盖零件图，DXF 格式。箱盖外形和附件尺寸在 `layout/housing_detail.py` 中统一确定，三维和二维共用。

**不做（第一版）：**

- 大规模国标数据录入。只录入计算链路**必须**用到的少量数值（电机、轴承、平键、齿形系数），每条注明来源并标记"待人工核对"。
- 只为证明"能跑通"的空壳演示。
- 锥齿轮、蜗杆等其他方案（数据结构留好扩展点，后续加）。
- 实体有限元（齿轮轮齿、箱体）。轴的刚度已用 CalculiX 梁单元复核，见 §7。

## 4. 计算方法的取舍

课程设计以教材方法为准（濮良贵《机械设计》、《机械设计课程设计》指导书），但教材里大量系数靠查图。本项目的处理方式：

- 能用公式的直接用公式（`Z_H`、`Z_ε`、`Y_ε`、`Y_β`、`K_Hβ` 经验式等），在代码和说明书里写明公式。
- 只能查图的系数（动载系数 `K_v`、寿命系数 `K_HN`/`K_FN`）用 ISO 6336 的解析近似，说明书里注明"近似"，并允许在任务书中手工覆盖。
- 查表的数值（齿形系数 `Y_Fa`、应力修正系数 `Y_Sa`）只存数值，线性插值。

所有可覆盖的系数都在任务书的 `overrides` 字段中，学生可以填自己从教材图表里查到的值，结果和说明书同步变化。

## 5. 单位

内部统一 SI：长度 m、力 N、应力 Pa、功率 W、转矩 N·m、转速 r/min（工程上转速习惯用 r/min，作为唯一例外）。说明书和界面显示时换算为 mm、MPa、kW、N·mm 等工程常用单位。

## 7. 有限元复核（`gongke_core/fem/`）

- 求解器 CalculiX（GPL）只以独立进程调用：`fem/ccx.py` 依次在环境变量 `GONGKE_CCX`、PATH、FreeCAD 安装目录中查找 `ccx`，要求版本 ≥ 2.21。FreeCAD 工作台把 FEM 首选项里的 ccx 路径（默认是安装目录 `bin/ccx`）通过 `GONGKE_CCX` 传给子进程。
- 轴用 **U1 梁单元**（两节点 Timoshenko 梁，按梁理论求解，节点输出转角），不用 B31/B32：ccx 会把 B3x 展开成三维实体单元，在支点和集中力处出现局部变形，实测细长等截面梁挠度偏小约 27%，不适合做复核。
- 模型与解析法一一对应（同样的轴段直径、支点、载荷和力偶），所以两者的差别只来自数值方法，四个示例最大相差 0.15%。教材刚度校核不计剪切变形，而这些轴短粗，剪切使挠度大 5%～30%，因此说明书同时列出“只计弯曲”“计入剪切”和有限元三列，校核仍按教材方法（第一列）。
- 输出：`fem/shaft*.inp`（可在 FreeCAD FEM 或 ccx 中复算）、`.dat`、`.frd`，`fem/comparison.md` 对照表，说明书加一章、`summary.json` 加 `fem` 字段。
