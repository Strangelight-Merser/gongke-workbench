## 事实与费用边界

- 工具操作、人工参数编辑和 Agent 自主建模分别标清；不把 API 改参数说成人工操作。不宣传单例成功率或平均效率。
- 第二次 robot4 dsh 已获用户批准：单会话、480 秒、不并行、不重试；失败即保留原片并停止汇报。模型、价格和实际 usage 记在 handoff.md。
- WorkBuddy 不展示。只展示真实已验收的 DeepSeek Harness 与当前安装引导。
- macOS 屏幕录制权限未确认；优先 Electron 内连续采集，个别真实截图单独标注。禁止把截图串联冒充连续录屏。
- 每个镜头的最终原片、时间段、速度和哈希以交付 sources.md / sources.json 为准。完整原片保留本地 out，不提交 samples 或媒体。

## 最终制作决定

不再付费运行 dsh。首次成功会话完整原序回放；第二次应用检查未发现内部轮廓偏差，检查段采用明确标记的确定性凸台示例。后端减速器命令和示例保留。无系统录屏权限，开场采用独立 Electron 原生 PDF 阅读器连续采集与历史真实 FreeCAD 参数窗口。
