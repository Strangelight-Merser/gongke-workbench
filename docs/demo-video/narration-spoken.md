# 构想引擎 · 路演口语旁白稿

供真人照读，也供神经语音分句合成。本轮只交样音，不调整成片。

**加粗是重音提示，不是提高音量的指令。** 短停约 0.2–0.3 秒，换气约 0.4–0.5 秒；括号里的提示不要念。每段末尾留给画面，不用拖长最后一个字凑时间。像对面坐着评委一样讲，第一段带一点疑问，第二段直接给出办法；结尾落稳，不用播音腔。

时长按现有 10 镜、总长 2:43 控制。汉字数不含标点、停顿指令和英文；预计净说话时长按 4–4.5 字/秒，再计 CAD、AI 和产品英文名的发音时间。镜头内的余量用于停顿与操作展示，不必全程说满。

回放、倍率、检查示例、修改练习和平台范围继续由现有角标说明。第3段只介绍记录和实际结果，不声称模型在画面中逐步重建；第6段只讲已验证的凸台尺寸检查；第9段不声称历史 Windows 安装验收属于最新版本。

## 真人录制与本轮样音

- CAD 逐字母读；AI 读英文字母；DeepSeek Harness 按英文产品名读。第一段的“来回切”和第二段的“你再接着改”稍微落重，其余重音自然带过。
- 先整段顺着讲，再在标注处换气。不要在每个逗号后都刻意停一下，也不要把“读图、建模”拆成两条口号。
- 本轮三版样音都使用第1、2段的同一份文字；先用于比较音色与口语节奏，约20秒，不硬对齐原来的12秒切镜点。确定声线后，才按实际动作调整全片入点。
- edge-tts 的 rate/pitch 不能保证复现真人的重音；本轮保持原生音高，用问句、短句和实插停顿改善节奏，不声称支持风格或情绪标签。

复现样音：使用已有环境运行 `/private/tmp/gongke-demo-video-venv/bin/python tools/demo-video/voice_samples.py`；输出位于 `out/demo-video/voice-samples/`，逐句文字、实际入点、停顿与试配时长见 `settings.json`。不下载模型，不安装依赖，不改动影片。
