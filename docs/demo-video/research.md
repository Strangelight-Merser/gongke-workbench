# 构想引擎参赛视频：研究与制作取舍

研究日期：2026-11-04。工作基线：`codex/demo-video @ f777ae0`。目标是约 3 分钟线上初评视频；不是把决赛的 5 分钟现场演示直接剪短。

## 研究方法与边界

以下研究读取了官方网页，下载实际视频，用 ffprobe 核对时长、音轨，并解码提取覆盖全片的画面序列进行视觉检查，不仅阅读营销文案。本地媒体、画面索引与网页快照在 `out/demo-video/research/`，不提交、不挪作参赛素材。浏览器观看服务不可用，因此**没有完成连续播放听审**；有音轨的片子不编造配乐风格或旁白原话。抽帧可以支持构图、可见字幕、操作顺序分析，不能精确证明每个转场的速度。下表时间分段为视觉采样所得的近似区间。

主样本是六支独立视频文件，来自四个产品；其中 Cursor 的两支操作短片是同一发布页的补充案例，不当作两个独立产品发布会。另看一支错误复现短片作对照。“优秀”是按本项目的可借鉴价值判断，不代表获奖认证。

## 六支主样本

### 1. Screen Studio：首页表格操作短片，5.55 秒

[官方页面](https://screen.studio/) · [实际媒体](https://screen.studio/landing/hero/hero-recording.mp4) · 本地 `screen.mp4` / `screen.jpg`。

- 钩子：一开始就在做事，选中的数值直接建立观看目标。
- 结构：选中数值 → Format 菜单 → Currency → 结果；在极短时间里完成一个可感知变化。
- 镜头：全局与局部来回切换，菜单处放大，较大的光标指向操作；移动中可见模糊帧，动作结束重新清晰。圆角窗口配深色背景，人物小窗固定在左下。
- 字幕：短英文词组用黑底白字显示，随动作推进，不放整段说明。该嵌入素材无音轨；字幕显示存在讲解语境，但不能据此声称听过声音或配乐。
- 借鉴：只在需要阅读数值/按钮时放大；动作完成留半拍。舍弃：我们不加人物小窗，也不每次鼠标移动都缩放，CAD 需要稳定的空间感。

### 2. Shapr3D：首页 CAD 到制造短片，43.10 秒

[官方页面](https://www.shapr3d.com/) · [实际媒体](https://cdn.prod.website-files.com/5fcde6f56fdac5769934eead%2F6a69b5a7c6a7716b55469f5f_homepage-hero_2026-07-28-comp_mp4.mp4) · 本地 `shapr.mp4` / `shapr.jpg`。

- 钩子：手和触控笔正在直接改变三维模型，先看到能力，再理解功能名。
- 结构：前约 10 秒盒体建模；中段支架/零件的跨设备编辑；末段导出、切片、打印、成品上墙。把“有模型”推进到“用得上”。
- 节奏与镜头：屏幕近景、斜侧拍、手部动作交替；模型始终是画面主体，蓝绿色选择态引导目光。依靠操作和结果切换，不依赖密集旁注。
- 字幕/声音：抽查帧没有持续解说字幕，下载文件无音轨，属于官网无声展示素材。
- 借鉴：用原生特征树和可编辑结果作为落点。舍弃：没有实物制造素材，就不借别人打印镜头暗示已经制造；不能照搬跨设备宣传。

### 3. Descript：首页 Underlord 工作流，25.53 秒

[官方页面](https://www.descript.com/) · [实际媒体](https://static-cdn.descript.com/descript-website/videos/home-hero-transparent.webm) · 本地 `descript.webm` / `descript.jpg`。

- 钩子：素材在左、请求在右，观众不用先学软件结构。
- 结构：请求编辑 → 处理重复/停顿 → 进一步完善 → 改语言/形态 → 出现新的成品画面；约每 3–6 秒一个结果变化。
- 镜头：左右两块界面叠放，大片留白，主要靠内容更新和淡入淡出引导注意，而不是全屏高速飞行。
- 字幕/声音：对话和界面文字承担说明，没有额外整段旁白字幕；此 WebM 无音轨。
- 借鉴：图纸与建模结果保留同框关系。舍弃：其官网经过设计的界面编排不能当我们的真实录屏模板；不能重画聊天内容或压缩等待而不标识。

### 4. Cursor：Computer Use 发布主片，102.40 秒

[官方发布页](https://cursor.com/blog/agent-computer-use) · [实际媒体流](https://stream.mux.com/B006e9hulodnlhryxf59bzuDVBPU8dFdmSabnuVSpnlM.m3u8) · 本地 `cursor-launch.mp4`（含音轨）、`cursor0.jpg`。

- 钩子：创作者与正在运行的产品同时出现，人的解释与产品证据交替。
- 结构：前段人物与屏幕建立情境；中段切到界面输入/选择；后段展示 Agent 留下的结果与可运行画面，再回人物。
- 镜头：双人中景、单人近景、屏幕特写、纯录屏交叉；纯录屏时大黑色指针和留边帮助定位。人物段承担信任，录屏段承担验证。
- 字幕/声音：采样画面未见持续烧录字幕；存在音轨，未完成听审，因此不判断配乐类型、音量或旁白语速。
- 借鉴：展示运行之后可核验的产物。舍弃：我们只有三分钟，不复制长人物对谈；不引用其内部 PR 比例来证明自己的产品。

### 5. Cursor：浏览器到表格的自主操作补充演示，63.10 秒

[官方发布页中的研究演示](https://cursor.com/blog/agent-computer-use) · [实际媒体流](https://stream.mux.com/wrHAsAFQOCOtSFRUI74jyRu00nJObZQh1fDVXWbUmOCY.m3u8) · 本地 `cursor1.mp4` / `cursor1.jpg`。

- 钩子/结构：直接进入浏览器任务，浏览数据 → 选择/复制 → 表格导入 → 继续编辑和图表操作。价值来自连续因果关系。
- 镜头/节奏：完整桌面保留应用上下文，光标与菜单告诉观众“真的在操作”；画面信息量很大，小字在缩小后不易读。
- 字幕/声音：可见快捷键提示；下载的该演示视频轨无音轨，未发现解说字幕；不推断原网页外部声源。
- 借鉴：展示工具确实执行，不停在聊天回复。舍弃：不能把整个冗长桌面原速塞入竞赛片；我们的数值、结果需要专门停留和放大。

### 6. Cursor：插件链接验证短片，21.78 秒

[官方发布页中的 Building new features](https://cursor.com/blog/agent-computer-use) · [实际媒体流](https://stream.mux.com/YDsJJOXi2B00ymllL9ft202lX2wNwGs3Nn0001sjmNGreiE.m3u8) · 本地 `cursor2.mp4` / `cursor2.jpg`。

- 钩子/结构：插件页面 → 点击组件 → 打开对应源码 → 返回 → 验证下一个组件，展示“生成后再验证”。
- 镜头：窗口全貌与链接局部穿插，放大的光标、可见快捷键提示承担动作说明；切换页面后短暂停留。
- 字幕/声音：无持续解说字幕；下载视频无音轨。
- 借鉴：我们的“检查 → 在模型中定位 → 修订后复查”应成为核心镜头。舍弃：不逐个检查几十个按钮，只选一个能看懂的闭环。

补充对照：[同页剪贴板错误复现片](https://stream.mux.com/VRdPu00jtteEepfoVPQtPrItzi7wisScyUwWGsFSjnq4.m3u8)，6.75 秒，`cursor3.mp4`。点击后出现明确状态变化，很适合说明短镜头如何留下证据；没有上下文也容易误读，因此我们的红色“不符”必须同时说清是哪一个尺寸，不能只有红绿闪动。

## 制作指导与落地规则

| 指导来源 | 可确认的指导 | 本片执行方式（创作判断） |
|---|---|---|
| [Screen Studio：Auto Zoom](https://screen.studio/guide/auto-zoom) | 自动缩放围绕点击；无点击的段落应手动指定区域 | 数值和特征树用手动焦点；大多数时间保持模型全貌；放大只做 1.15–1.35 倍 |
| [Screen Studio：Cursor](https://preview.screen.studio/guide/cursor) | 支持调整光标大小、闲置隐藏、去抖动等 | 尽量录制短而明确的移动；不补画不存在的点击；模型静止展示不让光标乱晃 |
| [Netflix 简体中文字幕规范](https://partnerhelp.netflixstudios.com/hc/en-us/articles/215986007-Chinese-Simplified-Timed-Text-Style-Guide) | 给出每行 16 字的规范；连续语句不滥加省略号 | 借鉴短行和自然断句，不声称本片按 Netflix 交付；1080p 用约 38–44 px，通常一行，最多两行 |
| [Microsoft：语言与声线支持](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts) | 中文神经声线可供选择 | 样片用 zh-CN-XiaoxiaoNeural，正式片须听审术语、数字、停顿；不克隆真人声音 |
| [edge-tts 官方项目](https://github.com/rany2/edge-tts) | 支持指定声线、语速、输出音频和字幕；不支持任意自定义 SSML | 按句合成、分句对齐，不为赶时长粗暴加速整段；保留旁白文本和 SRT |
| [Cursor 发布页](https://cursor.com/blog/agent-computer-use) | 强调通过视频、截图、日志验证 Agent 产物 | 本片每个能力主张都落到真实模型、检查或导出文件；画面不能只剩对话 |
| [Shapr3D 官方短片](https://www.shapr3d.com/) | 实际画面展示从设计到可用产物的顺序 | 三分钟叙事采用“问题—一次任务—可编辑结果—工程交付”，这是基于观片的创作归纳，不是硬性行业公式 |
| [本地赛事通知](星光杯/大赛通知.pdf)第 4–5 页 | 场景价值 30%、AI 深度 30%、落地 25%、表达推广 15%；决赛是 5 分钟演示及创作过程汇报、3 分钟问答 | 线上片让评委看懂一次完整任务；不按评分百分比机械分秒，AI 深度通过工具操作与结果体现 |

赛事通知的可靠本地绝对路径：`星光杯/大赛通知.pdf`。另外第 5 页规定“开发平台：仅限使用中国移动 workbuddy 联名版”。用户确认前，分镜不得写“WorkBuddy 已完成本次 dsh 建模”；参赛适用范围待核实。

## 最终取舍

1. 学 Screen Studio 的注意力引导，不学每秒缩放与装饰性飞行动画；学 Shapr3D 的结果落点，不加入未做过的实物制造。
2. 学 Descript 的输入/结果同框关系，但本片只用实际产品画面，不重新绘制界面。学 Cursor 的生成后验证，不用聊天文字替代可运行成果。
3. 开场只用 10–15 秒建立一个学生问题；约两分钟留给图纸、原生模型、检查、修改与交付。片尾说清接入方式和已有验收，不堆协议名。
4. 视觉用工作台浅色界面、深蓝外框、少量青色强调；字幕与片头置于界面之外，避免遮住模型/特征树。缩放采用缓入缓出，不做弹簧回弹。
5. 样片无配乐。正式片也可仅保留清晰旁白；只有取得明确商业使用授权并存档来源后才加音乐。研究视频的声音、画面均不借用。
6. 真实 dsh 等待如压缩，持续标 `×N 加速` 并保存原片时间映射；删去等待则标“等待片段已剪辑”。确定性 MCP 重演必须标明“工具操作演示”，不能冒充 Agent 的自主运行。
7. 安装证据只说明已验证的平台与范围；macOS 真机、Windows CI 与 Windows CAD 真机分开，不将 CI 安装通过扩写成商业 CAD 全流程验收。
