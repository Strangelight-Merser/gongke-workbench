构想引擎 · Windows x64 版

开始使用
1. 将整个 ZIP 解压到本地文件夹，不要在压缩包内直接运行。
2. 打开“应用”文件夹，双击“构想引擎.exe”。请保留同目录的全部文件。
3. 无需安装 Python、Node.js 或 CAD 即可计算和生成文件。
4. 点击“新建工程”，选择一个专用空文件夹；填写任务书，或点击“载入教学条件”。
5. 点击“计算方案”，检查各阶段结果，再点击“生成模型与图纸”。
6. 生成的 STEP、DXF/SVG、PDF 和 Word/Markdown 说明书保存在工程目录的 revisions 中。

工程文件
修改条件后，历史成果会标为过期；重新生成会建立新修订，不覆盖旧文件。
发送工程给他人时，复制整个工程文件夹，包括隐藏文件。重新打开时选择该文件夹。
教学条件及其成果仅用于演示，计算和出图成功不等于实际机械设计或制造验收。

工程助手（可选）
在“模型服务”填写支持 Chat Completions 工具调用的服务地址、模型名和自己的 API 密钥。
默认只在本次会话使用密钥，不写入磁盘；勾选“在此设备保存密钥”才使用系统加密保存。
对话及工具结果保存在工程内，重新打开工程后可继续；未配置模型不影响手动计算和导出。
密钥不要放进共享工程或发给别人。当前自动化测试使用本机模拟模型，真实模型服务需另验。

FreeCAD（可选）
“可选插件/FreeCAD/GongKeWorkbench”是独立工作台。
将该文件夹复制到 FreeCAD 的用户 Mod 目录，然后重启 FreeCAD 并选择工科工作台。
用户 Mod 目录可在 FreeCAD Python 控制台输入 App.getUserAppDataDir() 查看，再进入其 Mod 子目录。
已有工作台请先保留原安装，不覆盖个人工程。
打开受支持的原生轴及关联 TechDraw 图纸后，在桌面侧栏选择 FreeCAD，点击“读取 FreeCAD 工程”。
先“另存工作修订”，再比较、应用尺寸修改，校核并导出图纸。

验收范围
本包面向 Windows x64，未做代码签名。保留系统安全保护；系统阻止运行时请记录提示并反馈。
构建记录见 build-info.json；桌面计算、生成、工程隔离和对话协议由 Windows 构建机验证。
本包不包含 SOLIDWORKS、AutoCAD 的软件或授权；两者真实宿主操作及现场安装仍待验收。
如遇问题，请提供操作步骤、错误截图和 build-info.json；不要发送 API 密钥。
